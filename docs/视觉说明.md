# README 视觉说明

受众：同时维护多个 Codex 任务的开发者与创作者。
一句话价值：Codex 话题实时命名，更好区分。
主要证据：三条合成任务的前后对比，用真实 emoji 展示类别和具体目标。
首次成功操作：安装完整插件，信任 Stop Hook，预览一个任务并核验自动触发。
视觉主题：侧边栏中被重新命名的一条任务。

配色：暖白背景 #F4F2EC、深绿文字 #21382E、绿色强调 #28644B、浅绿选中态 #DCE9DF、灰绿辅助文字 #66766E。
字体：系统无衬线与中文系统字体；大标题 74、示例标题 44～48、辅助说明 20～24。
形状：16～24 圆角、3 单位线宽、8 单位间距基准。
重复母题：三个模糊标题逐行转换为带 emoji 的具体目标，颜色轻量区分类别。
构图：内容示例与标题结合，少装饰；流程图承担独立运行的解释。

静态纯 SVG，无图片生成、脚本、远程字体、外部位图或动画。移动端的详细示例与流程也完整保留在 Markdown 中。
